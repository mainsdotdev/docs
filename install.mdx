Mains Desktop supports **macOS on Apple Silicon and Intel**. For a backend on Linux, use [Mains Server](/server).

## Install the desktop app

<Steps>
  <Step title="Download Mains">
    Get the latest DMG for your Mac from [GitHub Releases](https://github.com/mainsdotdev/mains/releases/latest). Choose `arm64` for Apple Silicon or `x64` for Intel.
  </Step>
  <Step title="Move it to Applications">
    Open the DMG and move **Mains** into **Applications**. Launch that copy.
  </Step>
  <Step title="Choose and sign in to an agent">
    Onboarding checks each runtime and helps you sign in. You can enable more agents later in **Settings → General → Active agents**.
  </Step>
</Steps>

<Note>
  Automatic updates require the app to run from **Applications**. A copy opened from a DMG or Downloads cannot replace itself.
</Note>

## Agent requirements

| Agent | Runtime | Authentication |
| --- | --- | --- |
| [Claude Code](/claude/configuration) | Bundled with Mains | Sign in through onboarding or the provider settings |
| [GitHub Copilot](/copilot/configuration) | Bundled with Mains | Sign in with a GitHub account that has Copilot access |
| [OpenAI Codex](/codex/configuration) | Install the Codex CLI | Run `codex login` or use the in-app sign-in flow |
| [Cursor](/cursor/configuration) | Install the Cursor Agent CLI | Run `agent login` |

Claude and Copilot do not need a separate CLI installation for the bundled runtime. Their runtime updates arrive with Mains.

### Install Codex

```bash
npm install -g @openai/codex
codex login
```

Mains checks CLI compatibility in **Settings → Codex**. Follow its update guidance if your installed version cannot provide a feature. See the [official Codex CLI guide](https://learn.chatgpt.com/docs/codex/cli).

### Install Cursor

```bash
curl https://cursor.com/install -fsS | bash
agent login
```

See the [Cursor CLI guide](https://cursor.com/docs/cli/overview) for installation details.

## Git tools

Code mode needs Git. Creating or publishing a GitHub repository and opening a pull request through the Git actions panel also needs the [GitHub CLI](https://cli.github.com), authenticated with `gh auth login`.

Signing in to the [GitHub connection](/github) does not authenticate `gh` or Copilot. Each connection has its own purpose.

Continue with the [quickstart](/quickstart).
