Open **Settings → Dashboard** to inspect the active backend's run activity. Filter to all providers or Claude, Codex, Copilot, or Cursor.

## Overview

The summary shows projects, runs today, sessions, and estimated cost.

Charts cover daily activity, hour distribution, cost by model, tool usage, success and failure status, and code changes. Recent sessions link you back to the recorded work.

## Usage and cost

Counts and estimates use the information reported by each provider. Missing usage is not proof that a run was free.

Subscription usage, rate limits, and invoices remain with the provider. For Codex, account usage appears in **Settings → Codex** separately from these local estimates.

For one response, hover its duration in the [transcript](/runs) to inspect available token and cache details.

## Scope

The dashboard summarizes runs recorded by the current backend. It does not merge histories from separate Mains machines.

These statistics are local records. Viewing the dashboard does not upload a usage report to Mains.
