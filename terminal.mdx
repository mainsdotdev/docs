Open the terminal in **Code** with its panel button or `⌘J`. It starts in the active workspace's directory and uses your system shell.

Use it to run a development server, inspect Git state, authenticate a CLI, or execute commands yourself.

## Interactive sessions

The terminal supports interactive input, streamed output, and resizing. Different workspaces can have separate terminal sessions.

For example, start the repository's local development server, then open its URL in the [in-app browser](/browser).

## Agent commands

Agent shell calls appear in the [run transcript](/runs) with their inputs and output. They execute through the provider's runtime.

The manual terminal is a separate interactive session. It does not mirror every agent command, and commands you type there follow your own shell access rather than the agent's sandbox.

## Modes and remote clients

Work and Chat hide the terminal. The desktop and web client support terminal streaming for Code workspaces. A remote web terminal runs on the connected backend's machine.

The iPhone companion does not provide a remote shell. For server-side commands outside the app, use your own terminal or SSH.

Customize the terminal shortcut in **Settings → Keyboard Shortcuts**.
