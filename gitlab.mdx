Connect GitLab.com or a self-hosted GitLab instance to import issues and open merge request summaries.

## Credentials

Create a personal access token on your GitLab instance with the `read_api` scope.

Open **Settings → Connections → GitLab** and enter:

- **GitLab Domain**: leave it empty for `gitlab.com`, or enter your instance's domain.
- **Personal Access Token**: use a token from that instance.

For a self-hosted instance, create the token there rather than at GitLab.com.

## Select and sync projects

Search by project name or namespace path, then save your selection. Use **Add Project** to change it later.

Use **Sync** for a manual refresh or enable [Auto Sync](/automations).

## Use the imported data

Attach issues as [task context](/linked-tasks). Link selected GitLab projects to a Mains [project](/projects) to scope that context.

Merge request summaries are imported records. Mains's live [pull request review](/pull-requests) interface is currently GitHub-specific.

## Disconnect

Choose **Revoke GitLab Access** to deactivate the Mains connection and remove selected projects and imported data.

Invalidate the token on your GitLab instance if you also want to revoke it at the source.
