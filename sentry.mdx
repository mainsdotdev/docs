Connect Sentry to import error signals and diagnostic context from selected projects.

## Credentials

Open **Settings → Connections → Sentry**. The form requires:

- **Auth Token**, with `project:read`, `event:read`, and `org:read` scopes.
- **Organization Slug**, the identifier in a URL such as `sentry.io/organizations/my-org/`.

Use the form's **Auth Tokens** link to create a token.

## Select and sync projects

Enter the credentials, continue, and search by project name, slug, or platform. Save the projects you want to monitor.

Use **Add Project** to change the selection. Refresh error signals with **Sync** or [Auto Sync](/automations).

## Investigate an error

Link Sentry resources to a Code [project](/projects), then attach a synced signal to your message. Add relevant source files and describe the behavior you want to fix.

Imported diagnostic detail gives the agent a starting point. Refresh the signal when you need current source data.

## Disconnect

Choose **Revoke Sentry Access** to deactivate the Mains connection and remove selected projects and imported signals.

Invalidate the auth token in Sentry if you also want to revoke it at the source.
