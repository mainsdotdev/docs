Connect Jira to import issues from selected projects.

## Credentials

The current Mains setup uses three fields:

- **Jira Domain**, such as `your-company.atlassian.net`.
- **Email**, for the account associated with the token.
- **API Token**, created through the Atlassian API token link in the setup form.

## Connect Jira

<Steps>
  <Step title="Enter your credentials">
    Open **Settings → Connections → Jira**, complete the three fields, and continue.
  </Step>
  <Step title="Select projects">
    Search by project name or key. Save the projects you want to sync.
  </Step>
  <Step title="Refresh issues">
    Use **Sync** for a manual refresh or enable [Auto Sync](/automations).
  </Step>
</Steps>

## Use ticket context

Link Jira projects to a Mains Code [project](/projects) and attach tickets from [Tasks](/tasks) or the composer `@` menu.

Imported tickets are snapshots of the source data. Refresh them when your prompt depends on a recent change.

## Manage the connection

Use **Add Project** to change the selection. **Revoke Jira Access** deactivates the connection and removes selected projects and imported Jira data.

Invalidate the API token in Atlassian's settings if you also want to revoke it there.
