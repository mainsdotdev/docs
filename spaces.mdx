A space is a custom profile that lets you configure how Jinzo behaves for a specific workflow or project context. Each space can have its own system prompt, default model, theme, and UI settings.

## **Creating a space**

Click **Cmd+N** and select **New Space**, or use the space switcher in the sidebar. Give your space a name, description, and optional icon.

## **Space settings**

Each space supports the following configuration:

| **Setting**       | **Description**                                                                 |
| ----------------- | ------------------------------------------------------------------------------- |
| **Name**          | Display name shown in the sidebar and space switcher                            |
| **Description**   | Short description of the space's purpose                                        |
| **Icon**          | Custom icon for visual identification                                           |
| **System prompt** | Custom instructions prepended to every agent conversation in this space         |
| **Model**         | Default LLM model for agent runs started in this space                          |
| **Theme**         | Light and dark background color overrides for the space                         |
| **UI config**     | Layout and visibility preferences specific to this space                        |

## **System prompts**

The system prompt is one of the most powerful space features. Use it to give agents persistent context about:

- Coding standards and conventions for a specific project
- Domain-specific terminology and constraints
- Preferred tools, frameworks, or patterns
- Review criteria or quality gates

The system prompt is included in every agent run started within the space, so you don't need to repeat instructions manually.

## **Switching spaces**

Use the space switcher in the sidebar to move between spaces. Each space maintains its own set of workspaces and configuration. The active space is stored in your app settings and persists across sessions.

## **Archiving and deleting**

- **Archive** a space to hide it from the sidebar while preserving all data
- **Delete** a space to permanently remove it and all associated configuration

Archiving is reversible -- you can restore an archived space at any time.
