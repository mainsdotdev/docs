Connect Linear to import issues from selected teams, including identifiers such as `ABC-123`.

## Connect Linear

<Steps>
  <Step title="Create an API key">
    Open **Settings → Connections → Linear**. Follow the setup form's link to Linear's personal API key settings and create a key.
  </Step>
  <Step title="Enter the key">
    Paste it into **API Key** and continue.
  </Step>
  <Step title="Select teams">
    Search by team name, key, or description. Save the teams you want to sync.
  </Step>
  <Step title="Sync issues">
    Use **Sync** to refresh the imported issues. Enable [Auto Sync](/automations) for recurring refreshes.
  </Step>
</Steps>

## Use issue context

Browse issues in [Tasks](/tasks), link a team to a Code [project](/projects), or attach an issue through the composer `@` menu.

The agent receives the selected imported context when you send your message. Workspace status does not automatically change the Linear issue's status.

## Manage the connection

Use **Add Team** to adjust resource selection. Choose **Revoke Linear Access** to deactivate the Mains connection and remove selected teams and imported data.

Revoke the API key in Linear if you also want to invalidate it at the source.
