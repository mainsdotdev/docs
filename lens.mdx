Lens captures the frontmost Mac window and puts it in the composer. Use it to show an error dialog, another app's document, or a design reference.

## Enable Lens

Open **Settings → Lens** and enable capture. Grant **Screen Recording** permission for window images.

Grant **Accessibility** when you also want readable text from supported window elements. Review or revoke either permission in macOS System Settings.

## Capture a window

Bring the other app's window to the front and press the default shortcut `⌘⇧Space`.

The capture appears in Mains as a context chip. Review it, remove it if needed, and send a message describing what you want the agent to do.

Lens adds context. It does not send your message automatically or start computer control.

## What the agent receives

The next message includes the window screenshot and any captured accessibility text. Once sent, this context can reach the selected AI provider.

Review captures before sending if a window contains unrelated private information.

## Settings and scope

Change the capture shortcut in **Settings → Lens**. Lens is a local macOS desktop feature; it is not available from the standalone browser client or the phone.

For feedback on DOM elements in a website, use [browser annotations](/browser).
