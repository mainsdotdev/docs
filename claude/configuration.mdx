Claude Code comes with Mains. Sign in during onboarding or open **Settings → Claude** to inspect your account and runtime.

Claude supports **Code**, **Work**, **Chat**, and [Atlas](/atlas).

## Settings and conversation controls

Settings includes the default permission mode, output style, and structured output. Choose a model, thinking, effort, and supported fast options in the composer.

Conversation settings stay with each chat. Opening an older chat does not replace the defaults for new conversations.

## Permission modes

| Mode | Behavior |
| --- | --- |
| Ask permissions | Ask before operations that need approval |
| Auto | Let Claude decide when to ask |
| Auto accept edits | Accept file edits while retaining other permission decisions |
| Plan mode | Plan before making changes |
| Bypass permissions | Bypass ordinary permission prompts |
| Don't ask | Deny operations that need ungranted approval |

Work and Chat apply their own [mode policies](/modes). Chat is read-only, and changing a permission default does not make an existing Chat run writable.

## Settings files

Mains enables user, project, and local settings sources by default.

| Scope | Path |
| --- | --- |
| User | `~/.claude/settings.json` |
| Project | `.claude/settings.json` in the working directory |
| Local | `.claude/settings.local.json` in the working directory |

Within these sources, local values take precedence over project values, then user values. Managed provider policy can impose additional restrictions.

In a worktree, project configuration is read from that worktree's root.

## MCP, skills, and commands

Mains reads Claude MCP configuration from the settings files, `~/.claude.json`, and the project's `.mcp.json`. See [MCP servers](/mcp-servers) for an example.

Claude discovers skills from `~/.claude/skills/` and `.claude/skills/`. Settings links to skills, agents, and slash-command directories.

The [Plugins](/plugins) page also supports Claude's plugin marketplace and install scopes.

## Subagents and output

Claude's delegated work appears in the subagent panel. See [Claude subagents and teams](/claude/agentteams) for the distinction between SDK subagents and interactive CLI teams.

Use a structured-output schema when the task requires a defined JSON result. It is separate from creating a document or Page.
