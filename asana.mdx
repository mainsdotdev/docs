Connect Asana to import tasks from selected projects.

## Connect Asana

<Steps>
  <Step title="Create a token">
    Open **Settings → Connections → Asana**. Follow the setup form's link to Asana's Developer Console and create a personal access token.
  </Step>
  <Step title="Authenticate">
    Paste it into **Personal Access Token** and continue.
  </Step>
  <Step title="Select projects">
    Search by project or workspace name. Save the projects you want to sync.
  </Step>
  <Step title="Sync tasks">
    Use **Sync** for a refresh or enable [Auto Sync](/automations).
  </Step>
</Steps>

## Use task context

Attach a task to your agent message from [Tasks](/tasks) or the composer `@` menu. You can link Asana projects to a Mains Code [project](/projects) to narrow the list.

The selected task supplies context. Changing a workspace's local status does not automatically update Asana.

## Manage the connection

Use **Add Project** to adjust the selection. **Revoke Asana Access** deactivates the Mains connection and removes selected projects and imported tasks.

Revoke the token in Asana to invalidate it at the source.
