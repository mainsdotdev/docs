## **Global Shortcuts**

| **Shortcut** | **Action**                        |
| ------------ | --------------------------------- |
| **Cmd+N**    | Create a new workspace            |
| **Cmd+S**    | Open settings                     |
| **Cmd+P**    | Focus the agent input             |
| **Esc**      | Close modals, settings, or menus  |
