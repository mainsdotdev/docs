## **Global shortcuts**

| **Shortcut**    | **Action**                        |
| --------------- | --------------------------------- |
| **Cmd+N**       | Create a new workspace or space   |
| **Cmd+S**       | Open settings                     |
| **Cmd+P**       | Focus the agent input             |
| **Cmd+Shift+F** | Open feedback modal              |
| **Esc**         | Close modals, settings, or menus  |
