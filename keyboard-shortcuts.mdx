Open **Settings → Keyboard Shortcuts** to change, disable, or restore supported bindings. These are the default macOS shortcuts.

## General and navigation

| Action | Default |
| --- | --- |
| Search Mains | `⌘⌥K` |
| New item | `⌘N` |
| Open Settings | `⌘⇧S` |
| Close Settings | `⌘⇧W` |
| Focus composer | `⌘⇧P` |
| Toggle sidebar | `⌘⌥S` |
| Toggle terminal in Code | `⌘J` |
| Toggle browser | `⌘⌥B` |
| Switch to Code / Work / Chat | `⌘1` / `⌘2` / `⌘3` |

## Code projects

| Action | Default |
| --- | --- |
| Add a local project | `⌘⇧O` |
| Clone a Git URL | `⌘⇧U` |
| Create a project | `⌘⇧N` |

## Browser

These apply while the embedded browser is active.

| Action | Default |
| --- | --- |
| Focus address | `⌘L` |
| Find on page | `⌘F` |
| New / close tab | `⌘T` / `⌘W` |
| Previous / next tab | `⌃⇧Tab` / `⌃Tab` |
| Back / forward | `⌘[` / `⌘]` |
| Zoom in / out / reset | `⌘+` / `⌘−` / `⌘0` |
| Print | `⌘P` |

## Editor and Lens

| Action | Default |
| --- | --- |
| Save the current code file | `⌘S` |
| Add selected code to chat | `⌘L` |
| Capture frontmost window with Lens | `⌘⇧Space` |

Lens's global shortcut is configured in **Settings → Lens**. The editor's `⌘L` and browser's `⌘L` act in their respective contexts.

## Customize

Choose an action and enter a binding. Mains reports conflicts with overlapping scopes and prevents reserved system shortcuts from being assigned.

A disabled action can still be available through its UI. Desktop shortcuts and native window controls are not all available in a standalone browser client.
