Access settings with **Cmd+S** or from the sidebar footer.

## **General**

| **Setting**             | **Description**                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------- |
| **Run detail level**    | Control how much detail is shown during agent runs -- toggle visibility of tool calls and outputs  |
| **Prevent sleep**       | Keep your Mac awake while an agent run is active                                                  |
| **Theme**               | Choose between Light, Dark, or System (follows your macOS appearance)                             |

## **Notifications**

| **Setting**              | **Description**                                                  |
| ------------------------ | ---------------------------------------------------------------- |
| **Run complete**         | Show a notification when an agent run finishes                   |
| **Tool approval**        | Show a notification when an agent is waiting for tool approval   |

## **Personalization**

Customize your profile information used across Jinzo:

- **Display name**, **email**, **company**, **job title**
- **Website URL** and **avatar URL**
- **Bio** / description

## **Copilot settings**

| **Setting**              | **Description**                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------ |
| **Bypass permissions**   | Allow Copilot full file and terminal access without requiring approval for each tool call   |
| **Quick actions**        | Show or hide quick action buttons in the workspace toolbar                                  |

## **Apps & connections**

Manage your connected services from the **Apps** tab. See which integrations are active, connect new ones, trigger manual syncs, or revoke access. Connections are grouped by category:

- **Developer Tools** -- GitHub, GitLab, Linear, Jira, Asana, Trello, Notion
- **Monitoring** -- Sentry

## **Software updates**

Jinzo checks for updates automatically. From the General settings tab you can:

- View the current version
- Check for new updates
- Download and install updates with progress tracking
