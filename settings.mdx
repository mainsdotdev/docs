Open **Settings** from the rail or press `⌘⇧S`. Provider sections are available in the Settings navigation.

## Sections

| Section | What it controls |
| --- | --- |
| General | Run detail, active agents, menu bar, prevent sleep, and app updates |
| Appearance | Light/dark preference, themes, accents, colors, fonts, and app icon |
| Notifications | Run completion and tool-approval notifications |
| Git | Worktree preference and default commit/PR instructions |
| Lens | Window capture, shortcut, and macOS permissions |
| Keyboard Shortcuts | Customize or disable supported shortcuts |
| Connections | Issue trackers, Sentry, and Socket.dev |
| Dashboard | Local run and usage statistics |
| Archive | Archived workspaces and conversations |
| Claude, Codex, Copilot, Cursor | Account, runtime, and provider-specific options |

[Mains Connect](/relay/overview) is a top-level destination for hosting and connecting backends. **Projects** opens from project controls; its settings depend on whether it is a code project or collection.

## General

**Run Detail** controls the transcript's detail level. **Prevent Sleep** keeps the host awake while work is active. Enable **Menu Bar Icon** to see running tasks and [requests that need you](/approvals).

**Active agents** controls which providers appear in the space picker. Disabling a provider does not delete its history.

The app checks for updates and shows installation progress here. Run Mains from **Applications** for self-update.

## Appearance

Choose an app-wide theme or a different theme for each provider. The built-in presets offer light, dark, or both palettes, depending on the theme.

Adjust accent, background, foreground, contrast, UI font, code font, and their sizes. Appearance changes take effect without a reload.

Choose the **Default** or **Atlas** Dock icon. Platform appearance support depends on your macOS version.

## Git

Worktrees are off by default on new installs. Enable them for independent working directories when tasks will run in parallel.

Set **Commit Instructions** and **PR Template Instructions** to guide generated text. A project's configured instructions take precedence.

See [Workspaces](/workspaces) and [Git actions](/git-actions).

Conversation controls such as model and effort belong to individual chats. Loading an old chat does not change the defaults for new ones.

## Archive and notifications

Restore archived workspaces or runs from **Archive**. Restoring a workspace does not recreate removed files.

Configure notification types under **Notifications**. macOS notification permission must also be enabled.
