Press `⌘⌥K` to search Mains.

The command menu combines actions with your work: projects, workspaces, recent runs, and documents. Conversation search can match text said inside a run, so you do not need to remember its title.

## Open a result

Type a phrase, select a result, and open it. Commands can take you to settings or start an action; content results return you to the relevant workspace, chat, or document.

Search uses the active backend's data. Connecting to a different Mains server changes the work available to search.

## Search inside a surface

| Surface | Search |
| --- | --- |
| Workspace files | File name, path, and content, respecting `.gitignore` |
| Review | Changed-file paths |
| Atlas | Library search, category, and project filters |
| Tasks | Issue or PR search and filters |
| Browser | `⌘F` for the active page |

Change the command-menu shortcut in **Settings → Keyboard Shortcuts**.
