Use Codex's **Image Gen** skill to create images from a description or edit attached references. Mains can show the result in the conversation and in Atlas.

The skill must be available and enabled in your Codex runtime. A separately installed marketplace plugin is not always required; use the capability shown in your installed skills list.

## Create from Atlas

<Steps>
  <Step title="Open New image">
    Open [Atlas](/atlas) and choose **New image**.
  </Step>
  <Step title="Describe the image">
    Write a brief or choose a template such as Poster, Illustration, Product photo, Icon, or Infographic.
  </Step>
  <Step title="Add a reference">
    Attach, paste, or drop an image when you want an edit or a result guided by an existing visual.
  </Step>
  <Step title="Send and review">
    Mains starts a Codex Work conversation with the Image Gen skill. Continue in that chat to ask for changes.
  </Step>
</Steps>

If the skill is missing or disabled, the image workspace gives setup guidance and a refresh action. It does not silently start an ordinary text task.

## Create in a chat

Select Image Gen from the skill menu and give a visual brief:

```text
Create a square illustration of a small observatory at dusk.
Use warm interior light, a dark blue sky, and no text.
```

For an edit, attach the source image and describe the specific changes. Generated images open in a preview when clicked.

## Keep the original

Download the original image or choose **Save to Atlas**. Seeing it in Atlas's generated view does not create a permanent copy until you save it.

The saved Atlas copy survives deleting the conversation. See [Atlas](/atlas#save-a-file-permanently) for ownership and saving behavior.
