title: "Computer Use"
description: "Let Codex operate supported app and browser interfaces through an installed integration"

---

A Computer Use integration gives Codex tools for inspecting and operating supported user interfaces. It can use screenshots, clicks, typing, scrolling, and other actions to complete a task in an app or browser.

The environment depends on the installed plugin. Do not assume Computer Use always runs in a virtual machine or is isolated from your Mac.

## Set up the integration

<Steps>
  <Step title="Open Plugins with Codex">
    Select a Codex space and open [Plugins](/plugins).
  </Step>
  <Step title="Find the available computer tools">
    Open the relevant Computer Use or browser plugin. Read its supported environments and setup requirements.
  </Step>
  <Step title="Complete setup">
    Install it and grant only the macOS or browser permissions it requires. Availability depends on your account and the plugin.
  </Step>
  <Step title="Start a task">
    Open a Codex conversation and specify the app or page, the intended result, and which actions need your review.
  </Step>
</Steps>

## Give a concrete task

```text
Open the staging site and check the account settings flow.
Report layout and validation problems. Ask before submitting changes.
```

Follow the tool activity in the transcript. Connected tools and the provider can request [approval](/approvals) before an operation.

## Bring visual context

Use [browser annotations](/browser) for selected web elements or [Lens](/lens) for a Mac window. A screenshot attachment helps explain the task, but does not itself grant computer control.

## Access boundaries

A Codex filesystem sandbox and a computer-control plugin are separate access paths. A plugin operating a signed-in app can act with that app's permissions.

Review the integration's current access and the task's effects before allowing changes, purchases, or publication. Prefer a service's API or CLI when it provides a suitable operation.
