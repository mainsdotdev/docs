Connect Trello to import cards from selected boards.

## Credentials

The setup requires an **API Key** and **Token**.

Open **Settings → Connections → Trello** and follow the form's link to Trello's Power-Ups administration. Copy your API key, use its token link to authorize access, and copy the resulting token.

## Select boards

Enter both credentials and continue. Search the available boards and save the ones you want to sync.

Use **Add Board** to change the selection. Refresh cards with **Sync** or [Auto Sync](/automations).

## Use card context

Find synced cards in [Tasks](/tasks) or the composer `@` menu. Link boards to a Mains [project](/projects) to narrow task context.

Review the card's imported detail before sending it to an agent when you need the latest requirements.

## Disconnect

Choose **Revoke Trello Access** to deactivate the Mains connection and remove selected boards and imported cards.

Revoke the token in Trello to invalidate it at the source.
