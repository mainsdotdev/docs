<AccordionGroup>
  <Accordion title="Which platforms are supported?">
    Mains Desktop is for macOS on Apple Silicon and Intel. [Mains Server](/server) runs on macOS or Linux and provides a browser interface. The [iPhone companion](/mobile) controls a backend; Android has not shipped.
  </Accordion>
  <Accordion title="Do I need a repository for every chat?">
    No. Claude and Codex support [Work and Chat](/modes) without a repository. Code uses projects and workspaces. Atlas Page conversations use Work.
  </Accordion>
  <Accordion title="Do Claude and Copilot need a separate CLI install?">
    Their runtimes are bundled with Mains. Sign in during onboarding or through provider settings. Codex and Cursor need their own installed CLIs. See [Install](/install).
  </Accordion>
  <Accordion title="My agent is unavailable or signed out">
    Enable it in **Settings → General → Active agents**, then open its provider Settings section. Check runtime status and account authentication. For installed CLIs, use **codex login** or **agent login** as appropriate. Copilot, GitHub Connections, and GitHub CLI authentication are separate.
  </Accordion>
  <Accordion title="Does every workspace have an isolated worktree?">
    No. New installs start with worktrees off. Turn them on in **Settings → Git**, or create another worktree from the project. Chats sharing one workspace share its files.
  </Accordion>
  <Accordion title="A branch switch or worktree creation failed">
    Read the Git error. Check whether the branch is already checked out in another worktree, whether the path already exists, and whether uncommitted files conflict. Inspect **git worktree list** before changing worktree records.
  </Accordion>
  <Accordion title="An archived workspace came back with missing files">
    Restoring the workspace record does not recreate a directory removed by an archive script or another tool. Restore the checkout separately, then verify its path. Archive itself does not automatically delete a worktree.
  </Accordion>
  <Accordion title="A run is waiting or appears stuck">
    Check the conversation and menu bar for a pending [approval or question](/approvals). Use Stop if you need to cancel. Stopping leaves file changes for you to review; it does not Undo them.
  </Accordion>
  <Accordion title="Why can I not Undo a turn?">
    Overlapping edits can mark it as shared, and later changes can prevent the reverse patch from applying. Inspect [turn changes](/turn-changes) and the current diff. Separate worktrees reduce overlapping file edits.
  </Accordion>
  <Accordion title="My queued Codex message stopped sending">
    Stop, failure, archive, disconnection, or a backend change pauses delivery. Resume the queue explicitly. Unsaved queue state disappears on reload or app close.
  </Accordion>
  <Accordion title="A skill, plugin, or MCP tool is missing">
    Check the selected provider and run mode, installation scope, enabled state, and connection authentication. Refresh capabilities or start a new session. Claude settings do not configure every other provider.
  </Accordion>
  <Accordion title="Image creation in Atlas is unavailable">
    Check Codex's account and CLI status and whether the **Image Gen** skill is available and enabled. Use the image workspace's refresh action after setup.
  </Accordion>
  <Accordion title="Will Atlas keep a generated file if I delete its chat?">
    Only an explicit **Save to Atlas** makes a permanent file copy. Items shown under Generated or Uploads remain run-owned until saved. Native Pages already have their own library lifecycle.
  </Accordion>
  <Accordion title="GitHub issues or PRs do not appear">
    Check the GitHub connection, token permissions, and selected repositories. Sync for issue freshness. The PR inbox fetches live GitHub data separately. Creating a PR through Git actions also needs authenticated **gh**.
  </Accordion>
  <Accordion title="The phone cannot connect">
    Check that the backend is running and awake and that the phone can reach its advertised address. Production mobile builds need a secure endpoint such as Tailscale HTTPS. A revoked token needs fresh pairing; a version mismatch needs an update.
  </Accordion>
  <Accordion title="Desktop and Server report that the database is already in use">
    They use the same data directory by default. Quit one backend before starting the other, or choose an isolated server directory with **--data-dir**. Do not remove the ownership lock while a backend is running.
  </Accordion>
  <Accordion title="macOS asks for Mains Safe Storage Keychain access">
    Mains uses this entry to encrypt and read connection credentials. Allow access when you want those connections to work. Denying it can prevent stored credentials from being read.
  </Accordion>
  <Accordion title="How do I back up local work?">
    Stop the backend and preserve its whole data directory, including attachments, collection sources, and Atlas files alongside the database. Your repositories and provider credentials may need separate backups.
  </Accordion>
  <Accordion title="Is Bridge available for cross-device sync?">
    [Bridge](https://mains.dev/bridge) is announced as coming soon. Current remote access connects clients to one running backend; it does not synchronize independent backend databases.
  </Accordion>
</AccordionGroup>

If you need help, email [team@mains.dev](mailto:team@mains.dev) or open an issue on [GitHub](https://github.com/mainsdotdev/mains/issues). Include the Mains version, provider, and relevant error text.
