title: "Connection auto sync"
description: "Refresh connected-service data on an interval while the backend runs"
icon: "arrows-rotate"
---

Connection Auto Sync refreshes imported issues, tasks, and signals. It runs a sync job, not an agent conversation.

For scheduled agent prompts, use [Pulse](/pulse).

## Enable Auto Sync

Open **Settings → Connections**, open the connected provider's management view, and turn on **Auto Sync**.

Choose an interval: **15 minutes**, **30 minutes**, **1 hour**, **2 hours**, **4 hours**, **8 hours**, or **24 hours**. Enabling the UI control starts with 30 minutes.

The management view shows the last sync time.

## What it refreshes

Sync uses the connection's selected repositories, teams, projects, or boards. Only resources you can access are available to import.

The configuration persists across restarts. Scheduled jobs run on the backend that owns the connection, so the desktop or server must be running.

## Manual refresh

Use **Sync** in Connections for an immediate refresh. It does not require Auto Sync to be enabled.

If items are missing, check authentication and resource selection before retrying.

## Turn it off

Disable Auto Sync to stop recurring refreshes. This keeps the service connection and its selected resources.

Revoke the connection when you want to deactivate its credentials in Mains and remove imported data. To invalidate the token at the service, revoke it in that service's settings too.

The current Auto Sync interface does not configure arbitrary webhooks or event-triggered agent tasks.
