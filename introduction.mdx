Mains is a macOS app for working with **Claude Code**, **OpenAI Codex**, **GitHub Copilot**, and **Cursor**. You choose the provider, bring in context, follow the work, and review the result.

Use **Code** for repositories, **Work** for documents and other tasks, and **Chat** for conversations with read-only file access. **Atlas** keeps the pages, documents, and images you want to return to.

## How the pieces fit

| Concept | What it holds |
| --- | --- |
| [Space](/spaces) | Your agent provider, mode, instructions, and appearance |
| [Project](/projects) | A code repository and settings shared by its workspaces |
| [Workspace](/workspaces) | A checkout or worktree where Code runs execute |
| [Collection](/collections) | Related Work or Chat conversations and shared sources |
| [Run](/runs) | A conversation with its messages, tool calls, attachments, and usage |
| [Atlas](/atlas) | Native Pages and saved copies of documents and images |

Claude and Codex support all three modes. Copilot and Cursor currently support Code.

## Review while you work

Watch tool activity in the transcript, answer [approval requests](/approvals), and continue a run later. In Code, inspect [turn changes](/turn-changes), leave [diff comments](/diff-viewer), and use [Git actions](/git-actions) to commit and open a pull request.

In Work, open [documents](/documents) beside the chat and save useful results to Atlas. Connect [plugins](/plugins), [MCP servers](/mcp-servers), or [skills](/skills) when a task needs more tools.

## Choose where it runs

Your Mac keeps your repositories and run history by default. Getting started does not require a Mains account. Prompts and the context an agent uses go to the provider you select. See [Privacy](/privacy).

The [standalone server](/server) runs the backend and web interface on macOS or Linux. [Mains Connect](/relay/overview) lets another desktop or the [iPhone companion](/mobile) reach your own backend.
