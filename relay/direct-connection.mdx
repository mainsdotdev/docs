Use a Direct URL when the backend is already reachable over a trusted network or a secure endpoint.

## Expose the backend

For the running Mac app, enable **Network access (LAN)** or **Tailscale HTTPS** in [Mains Connect](/relay/share-this-machine).

For Server, choose a corresponding startup option:

```bash
mains serve --lan
```

or:

```bash
mains serve --tailscale-serve
```

Use the address advertised by that backend. The default HTTP and WebSocket port is **8787**.

## Connect from Desktop

Open **Mains Connect**, add a backend, and choose **Direct URL**.

Enter a name, WebSocket URL, and owner token. The form accepts `ws://` or `wss://`:

```text
ws://192.168.1.20:8787
wss://devbox.example-tailnet.ts.net
```

Use your real advertised address. Select the saved entry to connect.

## Transport choices

Plain `ws://` is unencrypted and should stay on a trusted LAN. Use Tailscale HTTPS, a properly configured TLS proxy, or an [SSH tunnel](/relay/ssh-tunnel) for access beyond it.

Direct public exposure needs a TLS proxy and an explicitly advertised public URL. Do not treat the owner token as a replacement for transport encryption.

## Other clients

Browsers use a one-use login link rather than the desktop token form. On Server, generate one with `mains web`.

Phones use [device pairing](/mobile), so they receive a separate revocable token.
