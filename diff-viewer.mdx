Open **Changes** from the Code session panel to review the workspace's current uncommitted changes. Review includes changes made by you, the agent, and other tools, including untracked files.

For one turn's patch, open its [change card](/turn-changes) instead.

## Read the diff

Changed files appear as ordered, collapsible diffs. Search the file list by current or renamed path to jump to a file.

Choose unified or split layout. Additions, removals, renamed files, and new files remain visible in their file context.

You can expand Review for more space and keep a floating chat beside the diff.

## Comment on a line or range

Click the line's comment control and write feedback. For several lines, drag **+** from the first line to the last, or click a line number and Shift-click another.

Pending comments appear as context in the composer. Choose the chat you want to send them to, add your message, and send.

```text
Address these review comments and explain how you verified the changes.
```

The saved prompt retains the comments and code they referred to. If the diff changes before you send, the comment keeps its original context instead of moving silently to another line.

<Note>
  Unsent comments are local drafts and disappear on reload. Send them when you want them recorded in the conversation.
</Note>

## Discard changes

The Git actions panel can discard a file or all working-tree changes. Read its confirmation: reverting an untracked file deletes it.

Discarding the workspace diff differs from [Undo for one turn](/turn-changes). It can remove changes from other turns or from your own edits.

## Commit and pull requests

Use [Git actions](/git-actions) after reviewing. Creating a PR needs a GitHub remote and authenticated GitHub CLI.

Review comments sent to your agent stay in the local conversation. To publish comments on a GitHub PR, use the separate [pull request view](/pull-requests).
