Atlas is your library for **Pages**, documents, images, and files from your conversations. Open it from the navigation rail.

Atlas works with **Claude and Codex**. Your saved library stays the same when you switch between those providers.

## Find your work

Use **All**, **Pages**, **Docs**, and **Images** to choose a category. Search, filter by project, and switch between list and grid views.

| View | What you find |
| --- | --- |
| All | Pages, generated files, saved files, and uploads |
| Generated / Your creations | Documents and images produced by conversations |
| Uploads | Files you attached to conversations |
| Saved to Atlas | Files you explicitly kept as library copies |
| Favorites | Saved items you starred |

Recent Pages appear in the sidebar. Generated files appear when the run identifies them as outputs; Atlas does not import every file from a workspace.

Browser annotation captures stay with their conversation but are omitted from automatic library listings. You can explicitly save a capture to Atlas when you want to keep it.

## Start a Page

Choose **Start a page**, complete the “Create a page about…” prompt, and send it. The agent writes a native [Page](/pages) that you can edit alongside it.

You can also start from **Project brief**, **Research notes**, **Decision log**, **Launch checklist**, or **Brainstorm**.

Each Page has its own chat. Ask for edits, start a new Page chat, or return to an earlier one. Page chats use Work mode without changing your space's saved mode.

## Save a file permanently

A conversation's generated files and uploads remain owned by that conversation until you choose **Save to Atlas**.

Saving copies the file into the library. That copy survives deletion of the source conversation. It is a snapshot; later edits to the original do not update the saved copy.

<Note>
  Seeing a file in **Generated** or **Uploads** does not mean it has a permanent Atlas copy. Choose **Save to Atlas** for files you want to retain independently.
</Note>

## Make images

Choose **New image**, describe the result, and optionally attach a reference image. Templates help you start a poster, illustration, product photo, icon, or infographic.

This uses Codex's **Image Gen** skill. Mains checks whether the skill is available and enabled before sending. See [Image generation](/codex/image-generation).

## Organize and recover

Give Pages a project, icon, and cover. Star saved items you use often.

Pages and saved files can move to **Trash**, where you can restore them or confirm permanent deletion. Generated files still owned by a run follow that run's lifecycle instead.

Export Pages as Markdown or JSON when you want to use them outside Mains.
