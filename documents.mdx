Open documents from an agent reply, the Work session panel, or [Atlas](/atlas). The viewer lets you inspect the result beside the conversation.

## Supported previews

| Format | Extensions |
| --- | --- |
| Word | `.docx` |
| Excel | `.xlsx` |
| PowerPoint | `.pptx` |
| PDF | `.pdf` |
| Markdown | `.md`, `.markdown` |
| Plain text | `.txt` |

Legacy Office formats such as `.doc`, `.xls`, and `.ppt` use the external-app fallback. If a preview cannot render a file, use **Open with…**.

The viewer previews files. Use an agent follow-up or the appropriate external editor to change an Office document. Native [Atlas Pages](/pages) have their own editable block interface.

## Sources and deliverables

In Work, **Sources** shows material used by the run. **Deliverables** shows output files the agent produced.

A temporary rendering image used to preview a document is not a separate deliverable. A file's appearance in Deliverables does not create a permanent Atlas copy.

Ask the agent for a concrete output and format:

```text
Create a project brief as a Word document.
Use the attached notes and include a milestones table.
```

## Export and save

Choose **Save a copy…** to put the original file where you want it. Image downloads also retrieve original bytes, even when the chat shows a smaller preview.

Choose **Save to Atlas** to keep a library snapshot that survives deletion of the conversation. To preserve a later edit, keep a new copy of that result.

## Attachments

Uploaded files and images are saved with their conversation and retained when you fork or archive it. You can find them under Atlas's **Uploads** view.

Deleting a conversation can remove its run-owned files. Save important material to Atlas or export it first.
