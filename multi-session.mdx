You can keep several agent conversations running at once. Each run has its own transcript and conversation settings.

## Chats in one workspace

Open another chat tab to try a different task or approach. Switching tabs does not stop the earlier run.

All chats in the workspace use the same working directory. They can see and change each other's files. Coordinate edits or use separate worktrees for independent implementation tasks.

[Turn Undo](/turn-changes) is disabled for a turn marked as shared when another agent touched the same file.

## Separate worktrees

Enable **Settings → Git → Worktrees**, or create a worktree from your project. Each task then has its own directory and branch while sharing repository history.

Worktrees isolate working files. They still share Git refs, so a branch already checked out in another worktree cannot be checked out again.

## Different providers

Choose another [space](/spaces) to work with another provider. The provider determines available models, tools, permissions, and session features.

Claude, Codex, and Cursor support forking. Copilot supports continuing its session but does not expose fork.

## Work and Chat

Work and Chat use separate conversations without code workspace tabs. Group related runs in [collections](/collections) and share their sources.

For delegated work inside a run, see [Codex subagents](/codex/subagents), [Claude agent teams](/claude/agentteams), and [voice tasks](/voice).
